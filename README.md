# Illinois Mobile and Electronic Notary Services — website

Static site for https://illinoismobilenotaryservices.com, deployed on Netlify (publish directory: repo root, no build command).

- `_redirects` — old Square Online URLs → new pages (301)
- `_headers` — security and image cache headers
- `sitemap.xml`, `robots.txt` — search engine files (canonical host: illinoismobilenotaryservices.com, no www)
- Google Analytics `G-8SQPYLN700` and Google Ads load after cookie consent
